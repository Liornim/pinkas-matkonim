# פנקס מתכונים

אפליקציית מתכונים בעברית. קובץ HTML יחיד — בלי שרת, בלי שלב בנייה, בלי תלויות להתקנה.

**חי כאן:** https://pinkasmatkonim.netlify.app

## יכולות

- **קריאת מתכון מצילום מסך** — מקומית על המכשיר דרך Tesseract.js, בלי מפתח ובלי מכסה. לחלופין דרך Gemini עם מפתח אישי, שגם מתרגם לעברית.
- **חילוץ אוטומטי** של כותרת, שם היוצר, תפוקה, מרכיבים, כמויות ושלבי הכנה, תוך סינון רעשי ממשק.
- **המרת יחידות** — פאונד ואונקיה לגרם, פרנהייט לצלזיוס, אינץ' לסנטימטר, כולל שברים מעורבים.
- **ערכים תזונתיים לכל מרכיב** — קלוריות, חלבון, פחמימות, שומן, שומן רווי וסיבים.
- **מאגר מקומי** של כ-90 מרכיבים עם משקלי יחידה, בתוספת חיפוש מוצרים לפי שם או ברקוד ב-Open Food Facts.
- **הערכים המוצגים הם אלה שהמתכון מפרסם.** חישוב המרכיבים מוצג לצידם להשוואה, עם התראה על פער מעל 15%.
- **קטגוריות, קישור למקור, וסנכרון** בין משתמשים דרך Firestore.

## עקרונות שהנחו את הפיתוח

הפונקציונליות הבסיסית לא נשענת על שירות בתשלום או על מכסה. AI הוא שיפור אופציונלי בלבד.

נתונים שמגיעים מהפנקס המשותף נחשבים קלט לא מהימן ועוברים סינון לפני הצגה.

כשחסר מידע — למשל כמה מנות המתכון מניב — האפליקציה אומרת זאת במפורש במקום להשלים ניחוש.

## פיתוח

הכל נמצא ב-`index.html`. להרצה מקומית:

    python3 -m http.server 8000

## בדיקות

311 בדיקות שרצות ב-Node בלי דפדפן, מול קוד האפליקציה עצמו:

    node tests/qa.js
    node tests/qa2.js

הכיסוי כולל פירוק ארבעה כיתובים אמיתיים מאינסטגרם, המרות יחידות, חישוב תזונתי, חיפוש ברקוד, זיהוי שפה ותרגום, סינון קלט זדוני, ותאימות לאחור.
